# Release screenshots

Captured while testing the 2.0.0 Quick Settings flip tile on a Xiaomi 14T Pro
(Android 15 / HyperOS 2) at 1080x2400, then cropped to remove notifications,
status-bar details and data usage.

- `tile-swiftkey.png` — the expanded Quick Settings shade with the Keyboard
  Picker tile showing `SwiftKey`, the currently active keyboard. A tap flips it
  to Gboard; a long-press opens the native chooser.
- `chooser.png` — the app's brief opaque window while the native "Select input
  method" dialog is being requested.
